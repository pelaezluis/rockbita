# 🤘 Rockbita Rock Band · Landing Page

> “Somos la descarga más letal de Rock y Buena Energía”

Landing page / dossier digital de **Rockbita**, banda de rock cartagenera fundada en 2019. Show de rock en vivo en inglés y español con los clásicos de todos los tiempos, tributos y serenatas.

Hecha con **HTML5 puro** y **Tailwind CSS** vía CDN. No necesita dependencias ni build.

## 🎸 Secciones

- **Inicio**: portada con el logo neón y llamadas a la acción.
- **La banda**: historia e integrantes.
- **Repertorio**: bandas icónicas, tributos y serenatas rock.
- **Eventos**: bodas, cumpleaños, grados, aperturas y cierres de eventos, y shows para bares, hoteles y yates.
- **Escenarios**: Dogma, Hard Rock Cafe, Hotel Hilton Cartagena, Hotel Cartagena Plaza y eventos privados.
- **Galería**: fotos en vivo.
- **Contacto**: teléfono, correo, WhatsApp y redes sociales.

## 🛠️ Tecnologías

- HTML5
- [Tailwind CSS](https://tailwindcss.com/) (Play CDN)
- Google Fonts: *Metal Mania*, *Bebas Neue* y *Oswald*

## 🚀 Uso

Clona el repositorio y abre `index.html` en el navegador:

```bash
git clone <url-del-repositorio> rockbita
cd rockbita
open index.html   # macOS · en Linux: xdg-open index.html
```

También puedes servirlo con un servidor local:

```bash
python3 -m http.server 8000
# http://localhost:8000
```

Se puede publicar tal cual en GitHub Pages, Netlify o Vercel.
